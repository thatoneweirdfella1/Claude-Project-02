 # Problem-Reaction-Solution (PRP)

**Often mentioned in political or social manipulation contexts.**

a. **Create a problem** (or exploit an existing one).

b. **Wait for the reaction** (public outrage, fear, or demand).

c. **Present a solution** — the solution appears helpful but actually implements the original goal.
