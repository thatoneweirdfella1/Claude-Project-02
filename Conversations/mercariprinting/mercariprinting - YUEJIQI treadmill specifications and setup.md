**ASSISTANT:**
 Here are the common reasons why an Android phone keeps saying the Wi-Fi password is incorrect even when it's right:

**Most Common Fixes:**

1. **"Forget" the network and reconnect**
   - Go to Settings → Wi-Fi
   - Tap on your network name
   - Select "Forget" or "Forget Network"
   - Reconnect and re-enter the password carefully

2. **Case sensitivity issue**
   - Wi-Fi passwords are case-sensitive
   - Double-check uppercase/lowercase letters
   - Watch for confusing characters (0 vs O, 1 vs l vs I)

3. **Router issue, not phone issue**
   - Restart your router (unplug for 30 seconds)
   - Other devices may still work because they're already connected
   - Router may have MAC address filtering enabled

4. **Network congestion**
   - Router may have reached maximum device limit
   - Try disconnecting another device first

5. **Saved network corruption**
   - Android sometimes saves corrupted network data
   - Forgetting and re-adding usually fixes this

6. **Router security mode mismatch**
   - Your phone may not support the router's security type
   - Try changing router from WPA3 to WPA2 in router settings

**Less Common Issues:**

- **IP conflict:** Router may need to assign a new IP to your phone
- **Hidden SSID problems:** If network is hidden, manually add it
- **Special characters:** Some routers/phones have issues with symbols in passwords
- **Android software bug:** Check for system updates
- **Network reset:** Settings → System → Reset → Reset Wi-Fi, mobile & Bluetooth

**Quick Test:**
Can other devices connect with the same password? If yes, it's likely the "forget network" fix will work. If no other devices can connect, restart the router.

Try the "forget network" method first - it solves this problem about 80% of the time!
