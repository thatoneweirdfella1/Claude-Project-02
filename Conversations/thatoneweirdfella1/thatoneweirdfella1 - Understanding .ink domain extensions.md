**ASSISTANT:**
 A `.ink` extension is used for a few different things depending on context, but the most common one in modern use is:

**Ink scripting language** (by Inkle Studios) — a narrative scripting language designed for writing interactive fiction and branching dialogue systems. It's used in game development, particularly for choice-based games and story-driven games. Unity has a popular integration for it called Inkle's Unity plugin. Games like *80 Days* and *Heaven's Vault* were written using Ink.

The `.ink` file is plain text, human-readable, and uses a simple markup syntax for branching paths, variables, and conditional logic.

Other less common uses:

**Corel Draw / vector graphics** — older Corel applications used `.ink` for ink-related brush or pen data files.

**Pantone / printing** — some print workflow software uses `.ink` for ink configuration profiles.

**Generic placeholder** — occasionally developers use `.ink` informally for annotation or markup files specific to their own toolchain.
