# DIVERGENCE.AI — CANONICAL DECISION AUTHORITY v2

**Status:** CORRECTED AUTHORITY BASE — supersedes the old Site Contract as the denominator for completeness.

## 1. Authority rules

1. Explicit approved/user-set decisions control only the scope they actually decide.
2. Named frozen/canonical authorities control their stated scope.
3. An older approved decision remains valid until an authorized source explicitly supersedes that decision.
4. Source code, commits, tests, and deployments prove implementation/evidence; they do not create product requirements by existing.
5. An unresolved conflict remains a conflict. Timestamps do not choose the winner.
6. `OUT_OF_SCOPE` for one acceptance surface never means `OMIT FROM MASTER DECISION RECORD`.

## 2. Scoped Developer-Mode reconciliation

- **Ordinary users:** one adaptive interface with `Show advanced controls`; no ordinary user must identify as a developer.
- **Normal billing/provider use:** never requires Developer Mode and cannot rely on Developer approval.
- **Operator/project-owner domain:** Developer Mode is separately tracked below and must be reachable/functional for its intended operator.
- These statements do not contradict one another because they govern different scopes.
