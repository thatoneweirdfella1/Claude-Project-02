# DIVERGENCE Control Constitution

**Status:** G1 control authority, subordinate to later explicit user decisions

1. Exactly one task is active. An interruption keeps that task active.
2. A dependent task cannot start or be accepted until every design prerequisite and validation dependency is satisfied at its required status.
3. Work occurs only in `thatoneweirdfella1/Claude-Project-02` on existing `divergence/reliability-staging`; no AI creates a branch or repository without a new explicit user instruction.
4. `claude/remaining-second-pass-v1` is untouched safety/layout evidence. `divergence/reliability-v1` is the protected accepted baseline.
5. Staging is untrusted work. Commit, push, green tests, deployment, and self-check do not equal acceptance.
6. The author's strongest unilateral status is `Self-check passed`. `Independently verified` requires separate reviewer identity and retained review evidence.
7. Acceptance is a distinct transition after required verification; it cannot be inferred from wording, location, age, or apparent quality.
8. Every checkpoint updates the task, append-only ledger, evidence, handoff, and integrity state. A handoff is safe only after its remote commit is read back.
9. Every load-bearing artifact has an owner, location, acceptance test, evidence requirement, gate, and dependency edges.
10. Missing, stale, contradictory, unaudited, failed, blocking-Open, or contaminated prerequisites fail closed and name the exact permitted next action.
11. Invalidated upstream work marks every relying descendant potentially contaminated until it is revalidated or returned to a verified baseline.
12. No AI may silently change product intent, architecture, scope, identifiers, layout, authority, tests, or evidence criteria. Extra ideas go to the parking lot.
13. Design, implementation, executed testing, independent verification, user approval, acceptance, release, and production validation remain separate claims.
14. The short user view must be a projection of the same machine state as the audit view; it may simplify language but never status.
15. Automatic external AI review is optional convenience. Repository enforcement remains safe when it is absent.

Historical documents remain evidence, but any historical instruction to create per-layer or per-task branches is inactive where it conflicts with Rules 3–4 and the user's later recorded decision.
