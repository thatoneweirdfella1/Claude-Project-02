# Baseline audit procedure

1. Verify repository, remote, branch, source SHA, and governance baseline.
2. Recheck every surviving branch comparison recorded in `BASELINE-STATE-AUDIT.md`.
3. Run the full test/build suite on the selected source checkout.
4. Run focused inspection/tests for any commit proposed from a divergent branch.
5. Verify the five registries by exact set, not counts alone.
6. Recompute `LAYER-OBLIGATION-MATRIX.csv`, then classify each permanent ID at each layer against its exact resolved obligation.
7. Credit `PROVEN` only with a complete obligation-specific evidence record and a separate accepted independent-audit record.
8. Match every live claim to `/.well-known/divergence-build.json` or record the missing identity.
9. Record left-behind commits and work explicitly.
10. Have an independent AI/account review every initial `PROVEN` row.

This is the sole initial-credit event. Chat summaries and code appearance cannot promote ledger cells.
