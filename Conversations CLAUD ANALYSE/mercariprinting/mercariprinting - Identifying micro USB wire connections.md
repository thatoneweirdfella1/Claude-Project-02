**ASSISTANT:**
 You've got a cut Micro USB cable and you need to identify the wires to splice it back together.

Standard USB cable has 4 wires inside:

- **Red** = Power (+5V)
- **Black** = Ground (-)
- **White** = Data -
- **Green** = Data +

If you just want it for **charging only** (no data), you only need red and black. Match color to color when splicing and you're done.

If the wires in yours don't have color (some cheap cables use all-white or unlabeled wires), grab a multimeter set to continuity mode — touch one probe to a pin on the USB-A end and the other probe to each wire until it beeps. That tells you which wire connects to which pin.

The USB-A plug has 4 pins in a row:
- Pin 1 (far left) = Red / Power
- Pin 2 = White / Data -
- Pin 3 = Green / Data +
- Pin 4 (far right) = Black / Ground

Match those to the Micro USB end the same way and you're good to splice.

Touch one probe to a known pin on the USB-A end, then touch the other probe to each wire one at a time until it beeps. That wire is connected to that pin.

The USB-A pins are easy to identify visually — the connector is rectangular and the 4 pins are in a single row inside. Looking at it with the pins facing you and the flat side up:

- Pin 1 is on the far left = Power
- Pin 4 is on the far right = Ground

So start with those two since they're all you need for charging. Find the wire that connects to pin 1, mark it with a marker or piece of tape, then find the one connecting to pin 4. Splice red-to-red equivalent and ground-to-ground and you've got a working charge cable.
