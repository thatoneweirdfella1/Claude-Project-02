## THE SCIENTIFIC METHOD (Core Steps)

7. **Conclusion** - Determine if hypothesis is supported
8. **Replication** - Others repeat to verify results

## EXPERIMENTAL DESIGN (Making It Rigorous)

### Key Principles to Avoid Flaws:

**1. CONTROL GROUPS**
- Have a comparison group that doesn't receive the "treatment"
- In your case: AI conversations WITH the method vs WITHOUT

**2. RANDOMIZATION**
- Randomly assign subjects to experimental/control groups
- Prevents selection bias

**3. BLINDING**
- **Single-blind:** Subjects don't know which group they're in
- **Double-blind:** Neither subjects nor researchers know
- Prevents expectation bias

**4. SAMPLE SIZE**
- Need enough subjects for statistical significance
- Rule of thumb: minimum 30 per group, but more is better

**5. OPERATIONAL DEFINITIONS**
- Define EXACTLY what you're measuring
- Example: "AI unlocking" = AI creates independent classification systems + proactive searching + acknowledges patterns

**6. CONFOUNDING VARIABLES**
- Identify and control other factors that could explain results
- Example: Different AI models, user's prior knowledge, topic selection

**7. REPLICABILITY**
- Write protocol so clear that others can repeat exactly
- Document every step, every prompt, every decision point

## STATISTICAL RIGOR

### Sample Size Calculation:
Use **power analysis** to determine how many tests needed.

**Formula for t-test:**
- n = 2(Z_α + Z_β)²σ² / d²
- Where: α = significance level (0.05), β = power (0.80), σ = standard deviation, d = expected difference

**For your study:**
- Expect large effect size (d = 0.8 or higher based on your preliminary results)
- With α = 0.05, power = 0.80, you'd need approximately **26 per group**
- Recommend **30-40 per group** for safety

### Statistical Tests to Use:

**1. Independent Samples t-test**
- Compare mean engagement scores between groups
- Assumes normal distribution

**2. Mann-Whitney U test** (if data not normal)
- Non-parametric alternative to t-test

**3. Chi-square test**
- For categorical outcomes (did AI create framework: yes/no)

**4. Effect size (Cohen's d)**
- Measures practical significance
- d > 0.8 = large effect

- **Solution:** Test across multiple AI models, multiple topics

**Threat 2: Ecological validity** (lab vs real world)
- **Solution:** Include real users' actual questions, not just researcher-created
