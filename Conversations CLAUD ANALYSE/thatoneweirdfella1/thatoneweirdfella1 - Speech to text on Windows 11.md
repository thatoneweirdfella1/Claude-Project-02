**ASSISTANT:**
 On Windows 11, you have a couple of options for speech-to-text:

## Voice Typing (Built-in)
**Shortcut: `Windows key + H`**
- Works in any text field
- Click the microphone icon to start
- Supports auto-punctuation

## Windows Speech Recognition
1. Go to **Settings** → **Accessibility** → **Speech**
2. Toggle on **Windows Speech Recognition**
3. Or search "Speech Recognition" in the Start menu

---

For **live translation** specifically (speech in one language → text in another), Windows doesn't do that natively. You'd need:

- **Microsoft Translator app** (free, from Microsoft Store) — does live translation
- **Google Translate** (browser version) — has live transcription + translation
