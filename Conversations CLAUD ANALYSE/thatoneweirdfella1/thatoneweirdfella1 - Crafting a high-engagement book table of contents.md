**ONE. CONTRADICTIONS**

There is one real contradiction in the itineraries and it is serious.

The Master Rules Block in both itineraries tells the AI to "source first, write second, search for every named source before writing a word." But then the prompt packets give the AI the sources already pre-described in the What This Segment Covers and What This Chapter Covers sections. This creates a direct conflict. The AI is told to go find the sources independently, but the prompt has already told it what the sources say. A context-blind AI will read the pre-described source content as confirmed fact and skip verification entirely, because why search for something you've already been told the answer to.

The fix is to separate the two instructions clearly. The source list should say exactly what to search for but not what those searches will return. The current packets describe content. They should only describe search terms.

There is a secondary contradiction between the two itineraries. Itinerary A says the Segment A wow fact is non-negotiable and must open the chapter. Itinerary B says the opening wow fact must open the chapter. But neither itinerary defines what happens if the AI cannot verify the named wow fact. The source rules say never use an unverified quote. But the opening instruction says the wow fact is non-negotiable. If the AI cannot verify Hannah Rothschild's exact words, these two rules collide directly. There is no protocol for that collision.
