**ASSISTANT:**
 A **.crdownload** file is a **partial download file** created by Google Chrome (and Chromium-based browsers like Edge).

When Chrome starts downloading a file, it saves it with a `.crdownload` extension as a temporary placeholder. Once the download completes successfully, Chrome removes the `.crdownload` extension and you're left with the final file (e.g., `video.mp4`, `document.pdf`, etc.).

**Key things to know:**

- If a download is interrupted or paused, the `.crdownload` file stays on your disk — it contains whatever portion of the file was downloaded so far.
- You generally **can't open** a `.crdownload` file directly, since it's incomplete.
- If a download was nearly finished, some file types (like videos) might be partially playable, but it's unreliable.
- You can safely **delete** `.crdownload` files if you no longer need the download — they're just leftovers.

The name comes from **CR** (Chromium) + **download**.
