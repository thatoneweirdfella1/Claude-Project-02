# 1.3 Gap Categories

Four categories of intent-expression gaps, derived from the 10 real examples.

---

## Category Definitions

### Category A — Tangential Preamble

**Definition:** The user provides extensive backstory, context-setting, or framing before stating the actual question. The preamble is often relevant but the functional request is buried inside or at the end of it.

**Signal:** Message has a high context-to-request ratio. The question, when found, is structurally smaller than the setup surrounding it.

**AI default failure:** Responds to the narrative or context rather than the hidden request. Summarizes the backstory instead of answering the implied question.

---

### Category B — Emotional Intensity Distortion

**Definition:** The emotional register of the message (frustration, conspiracy framing, urgency, roleplay persona) dominates the surface reading and obscures the functional question underneath.

**Signal:** Emotional markers are the first and most prominent feature of the message. The actual informational need is secondary.

**AI default failure:** Responds to the emotional tone — either validating it, deflecting it, or over-cautiously refusing — instead of extracting the request it wraps.

---

### Category C — Compound / Buried Request

**Definition:** The actual request is embedded in structural noise — sentence fragments, self-interruptions, contradictions, or multiple partially-stated requirements that together describe a specific deliverable.

**Signal:** Message contains "and," "also," multiple noun phrases, self-corrections. Reading it once produces confusion; reading it twice reveals a coherent deliverable.

**AI default failure:** Picks one sub-requirement and answers only that, or asks a clarifying question instead of assembling the full picture from the fragments.

---

### Category D — Typo / Vague-Pronoun Corruption

**Definition:** The message is structurally simple but the literal words are damaged — by typos, autocorrect failures, vague pronouns with no local referent, or assumed shared context that doesn't exist in the current turn.

**Signal:** Words that don't exist, pronouns like "it" or "this" with no noun to attach to, or references to prior conversation content not present in the current message.

**AI default failure:** Takes the typo literally, asks "what do you mean by X?" without attempting phonetic reconstruction, or fails on the pronoun reference and requests clarification unnecessarily.

## Example Assignments

| # | Example | Primary Category | Notes |
|---|---------|-----------------|-------|
| 1 | ADHD Hyperfocus | A — Tangential Preamble | Life story before the question; request appears only at the end |
| 2 | Coincidences in the 30s | D — Typo / Vague-Pronoun Corruption | "it" and "the 30s" have no local referents; misspelled key term |
| 3 | Categorizing Events Through Multiple Perspectives | C — Compound / Buried Request | Fragmented lenses listed mid-sentence; assembled together = full spec |
| 4 | Celebrity Appearance / Body Double Theories | B — Emotional Intensity Distortion | Roleplay/jailbreak wrapper; actual request is rigorous analysis |
| 5 | ADHD-Friendly App Organizer | C — Compound / Buried Request | Self-interrupting specs; contradictory final line hides real requirements |
| 6 | Alternative Cancer Treatments | A — Tangential Preamble | Conspiracy framework as context-setting before buried question |
| 7 | Multi-Boot USB (Context Restoration) | D — Typo / Vague-Pronoun Corruption | Cascading typos + no explicit question + assumed shared context |
| 8 | Cheap Alternatives to Unisom | D — Typo / Vague-Pronoun Corruption | Autocorrect failure ("unison hat") corrupts product reference |
| 9 | Barrel Connector Wire Polarity | D — Typo / Vague-Pronoun Corruption | Typo + vague pronoun "this" + image without explanation |
| 10 | Apps Menu Flooded with Ads | B — Emotional Intensity Distortion | Pure emotional opener; informational need is implicit |

## Category Frequency

| Category | Count | Examples |
|----------|-------|---------|
| A — Tangential Preamble | 2 | 1, 6 |
| B — Emotional Intensity Distortion | 2 | 4, 10 |
| C — Compound / Buried Request | 2 | 3, 5 |
| D — Typo / Vague-Pronoun Corruption | 4 | 2, 7, 8, 9 |

Category D is the most common failure mode — not emotional expression or complexity, but raw signal corruption at the word level.

---

## Category-to-Technique Mapping

| Category | Primary T01 Response |
|----------|---------------------|
| A — Tangential Preamble | Scan from end; strip backstory; extract final verb-object |
| B — Emotional Intensity Distortion | Strip affect layer first; extract underlying informational need |
| C — Compound / Buried Request | Assemble fragments; resolve contradictions; prefer specific over vague |
| D — Typo / Vague-Pronoun Corruption | Phonetic reconstruction; domain-anchored pronoun resolution |
