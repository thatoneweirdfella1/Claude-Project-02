# 1.9 When NOT to Translate

Examples where raw input is already clear and the translator pipeline should be bypassed.
These inputs route directly to T18 (Minimal Pipeline Mode).

---

## Criteria for "No Translation Needed"

An input requires no translation when it has ALL of the following:
- One specific, unambiguous question
- No emotional content or frustration markers
- No vague pronouns without local referents
- No typos that change word meaning
- Specific nouns (no "it," "this," "the thing")
- Self-contained — does not reference prior context

---

## Example 1 — Keyboard Shortcuts for Windows 11

**File:** `erwinschrodinger61 - Closing lagging programs in Windows 11.md`

**Exact opening message:**
> "What keys do you press in windows 11 to close a program when it's lagging?"

**Why no translation is needed:**
Specific OS (Windows 11), specific scenario (lagging program), specific output requested (keyboard shortcuts). No emotional content, no pronouns requiring resolution, no ambiguity about goal or domain.

**T18 routing reason:** Single factual lookup. Haiku-level response appropriate.

## Example 2 — Testing a 12-Volt Battery

**File:** `erwinschrodinger61 - Testing 12 volt battery with multimeter.md`

**Exact opening message:**
> "How do you test the battery power of a 12 volt battery with a multimeter"

**Why no translation is needed:**
Specific tool (multimeter), specific subject (12V battery), specific procedure requested (how to test). No ambiguity, no emotion, no continuation context required, no corrupted tokens.

**T18 routing reason:** Procedural how-to. One correct answer. Haiku-level response appropriate.

## Example 3 — Types of Plantains

**File:** `erwinschrodinger61 - Types of plantains.md`

**Exact opening message:**
> "How many types of plantains are there"

**Why no translation is needed:**
Factual taxonomy question. Single noun (plantains), single question word (how many), neutral tone, no pronouns, no context dependency, no ambiguity in intent or scope.

**T18 routing reason:** Simple factual lookup. Haiku-level response appropriate.

## Decision Rule

```
IF message_length < 25 words
AND pronoun_count_without_referent = 0
AND typo_density < 0.1
AND emotion_score < 0.2
AND intent_count = 1
AND continuation_signals = false
THEN route → T18 (skip full pipeline)
```

---

## What NOT to Misclassify as "No Translation Needed"

These look simple but require extraction:

| Message | Looks like | Actually requires |
|---------|-----------|-----------------|
| "Will this work?" + image | Simple yes/no | Image context + polarity verification |
| "Prices for these 2 wigs" + image | Simple lookup | Product identification first |
| "What number did it say" | Simple recall | Pronoun resolution + prior context |
| "Wtf is this" + video | Simple complaint | Problem diagnosis from media |

The key differentiator: if the message relies on a pronoun, an image, or prior context to be answerable, it is NOT a clean T18 input even if the text itself is short.
